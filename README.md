(clone it, run it, start your aspect — night one is a study hall; teams
form week 2, when [weeks/week-02-repo-ritual.md](weeks/week-02-repo-ritual.md)
gets your team's repo created and protected).

Two rules hold all semester: **no AI-generated code merges unread** (the
diff, in hunk, hunk by hunk), and **verify what AI tells you by running the
code**. Everything else is commentary.
